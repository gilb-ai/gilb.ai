# gilb.ai

Public Company Brain website, hosted on GitHub Pages at [gilb.ai](https://gilb.ai).

- `/`: Company Brain landing page, stylesheet, and interactive examples.
- `/transformation/`: previous Gilbreth AI transformation landing page.
- `index2.html`: existing alternative design.

Static HTML, CSS, and JavaScript. No build step.

The authoritative source lives in the internal `workspace` repository under
`gilb.ai/`. Copy the published files here, commit, and push to `main` to deploy.
The `CNAME` file preserves the custom domain.
