# gilb.ai

Public Company Brain website, hosted on GitHub Pages at [gilb.ai](https://gilb.ai).

- `/`: toolkit home for consultants and internal AI-transformation leaders.
- `/therblig/`, `/therblig/how-it-works/`: Therblig — AI interviews plus screen context.
- `/brain/`: Company Brain landing page (no public prices; terms on request).
- `/platform/`: Company Brain — how it works.
- `/partners/`: partner program (white-label, referral, internal teams).
- `/cases/`, `/demurrage/`: cases and the demurrage pilot page.
- `/transformation/`: previous Gilbreth AI transformation page, kept for future use.
- `_old/`: archived alternative designs, excluded from the published site.

Static HTML, CSS, and JavaScript. No build step.

The authoritative source lives in the internal `workspace` repository under
`gilb.ai/`. Copy the published files here, commit, and push to `main` to deploy.
The `CNAME` file preserves the custom domain.
